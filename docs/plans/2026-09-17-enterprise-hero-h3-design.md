- 按用户的默认偏好，用内置 image2 制作一张首尾帧控制图，文字在图内生成，不后贴文字。
- 视频只使用 Atlas Cloud 的 `minimax/h3/image-to-video`，标准版 2K、12 秒、adaptive 比例、关闭 prompt expansion。
- 首尾帧使用同一构图，提交恰好一个视频任务；保存任务回执，网络异常不得盲目重复提交。
- 生成后检查清晰度、可读性、时间轴和循环，再压缩为站内文件并提取封面。
- 沿用原有暂停、减少动态效果、失败封面逻辑；保留旧视频；不发布生产。
